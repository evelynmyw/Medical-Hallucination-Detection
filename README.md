# Medical Hallucination Detection

Binary classifier for detecting hallucinated answers in medical QA (MedHallu dataset). Work in progress.

## Data and split

- Dataset: [`UTAustin-AIHealth/MedHallu`](https://huggingface.co/datasets/UTAustin-AIHealth/MedHallu). Each row is one question with one ground-truth answer and one hallucinated answer.
- Train / validation: `pqa_artificial` (9,000 questions), split **by question** 85/15 with `GroupShuffleSplit`.
- Test: `pqa_labeled` (1,000 questions). No question overlaps with `pqa_artificial`.
- Each question is expanded into two samples only *after* splitting (ground truth → label 0, hallucinated → label 1), so both answers to a question always land in the same split. `tests/test_split.py` checks this.
- Cleaning: dropped 1 duplicated question and 2 rows with a single-word answer (truncated generation `"VSL"`, non-answer `"P<0.05."`) from `pqa_artificial`.

| Split | Questions | Samples |
|---|---|---|
| train | 7,647 | 15,294 |
| val | 1,350 | 2,700 |
| test | 1,000 | 2,000 |

## Findings so far

### Answers can be told apart by surface features

**Length.** Ground-truth answers are longer than hallucinated ones in 78.4% (`pqa_labeled`) and 73.4% (`pqa_artificial`) of question pairs (median 37 vs 23 words in `pqa_labeled`).

**Style.** A bag-of-words logistic regression on the answer alone reaches 92.8% validation accuracy, suggesting that MedHallu's hallucinated answers are largely distinguishable by surface style rather than factual content.

Baselines (validation set, seed 42, threshold 0.5):

| Model | Input | Accuracy | F1 | AUC | Pairwise acc. |
|---|---|---|---|---|---|
| Length only | answer word count | 0.684 | 0.698 | 0.706 | 0.731 |
| TF-IDF + LR | answer | **0.928** | **0.928** | **0.980** | 0.983 |
| TF-IDF + LR | question + answer | 0.910 | 0.910 | 0.972 | 0.983 |

*Pairwise acc.*: share of questions where the hallucinated answer receives a higher score than the ground truth.

The most predictive words show what the style difference is. Ground-truth answers (written by the paper authors) hedge: *may, be, might, could, should, our, we, results, data*. Hallucinated answers (generated by an LLM) make confident causal or mechanistic claims: *significantly, enhances, due to, rather than, primarily, inversely, increases, exacerbates*.

Implication: a neural model's accuracy on MedHallu is only meaningful relative to these baselines. A model that reaches ~93% may simply have learned the same stylistic cues.
